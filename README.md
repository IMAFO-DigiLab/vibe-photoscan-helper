# Photoscan Helper

Photoscan Helper is a small browser-based tool to simplify and clean photographed documents. It uses OpenCV compiled to WebAssembly (opencv.js) to perform perspective correction, enhancement (CLAHE, denoising, sharpening), adaptive thresholding, rotation, and optional page-size normalization. The app supports single- and double-page scans and batch export as a ZIP of PNGs.

Key features
- Drag-and-drop or file picker to upload images (batch up to 30).
- Interactive editor to adjust document corners and rotate preview before processing.
- Enhancement controls: sharpening, denoise, adaptive thresholding, CLAHE, grayscale mode.
- Processed results preview with per-page controls and rotation.
- Export processed images as a ZIP with optional page size normalization (A3/A4/A5/A6).

Files
- `index.html` — application entrypoint (loads dependencies and app scripts).
- `styles/main.css` — custom styles.
- `src/services/opencvService.js` — OpenCV-based image processing service (perspective warp, enhancement, rotation, normalization).
- `src/components/ScannerEditor.js` — interactive editor component for framing and rotating images.
- `src/components/ResultView.js` — result preview and enhancement UI.
- `src/components/App.js` — main application state and UI orchestration.
- `src/main.js` — mounts the app into the page.

How it works (brief)
1. Upload images via the UI. The app stores them in a queue.
2. Use the `ScannerEditor` to drag corner points and rotate the preview as needed.
3. Press `Process Scan` to run OpenCV perspective warp + enhancement. Results appear in `ResultView`.
4. Tweak enhancement sliders per page; re-processing happens automatically.
5. Export all processed pages using the `Save All` button.

Running locally
1. Open `index.html` in a modern browser (Chrome, Edge, Firefox). No build step required.
2. If you prefer a simple static server (recommended to avoid file:// restrictions):

```bash
# from project root
python3 -m http.server 3000
# then open http://localhost:3000 in your browser
```

Notes and tips
- OpenCV (WASM) loads asynchronously; the app shows a loader while initializing.
- Rotations are applied in 90° increments to keep OpenCV operations simple and fast.
- The app is intentionally simple and uses UMD globals to avoid a bundler; refactoring into modules and a build step (Vite/Parcel) is straightforward if needed.
